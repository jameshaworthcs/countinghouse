# Security

Please report a vulnerability privately, through GitHub's **Report a vulnerability** button on this
repository's Security tab, not in a public issue. Include what you found, how to reproduce it (with
invented data), and what it lets someone do.

Expect an acknowledgement within a week. Fixes go into `main`; there are no maintained older
releases.

What the app guards, and how, is in [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) ("Security") and
[docs/SELF_HOSTING.md](docs/SELF_HOSTING.md).
